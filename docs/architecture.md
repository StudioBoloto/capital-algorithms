# Архитектура

Детектор работает причинно: решение для текущего кадра использует только
текущий и прошлые кадры.

1. ROS 2-адаптер приводит PointCloud2 к системе координат `x` вправо, `y`
   вперёд, `z` вверх.
2. Angular/ring sampling нормализует плотность 128-канального облака.
3. Локальная оценка профиля пути выделяет свободный габарит без внешней карты.
4. Причинная модель фона подавляет постоянную инфраструктуру.
5. Геометрический этап формирует компактный набор предложений.
6. Лёгкая range-image модель подтверждает препятствие.
7. Временная логика публикует тревогу после подтверждения в соседних кадрах.

Такой каскад отделяет дешёвую геометрическую фильтрацию от более точной
нейросетевой проверки. Он рассчитан на платформы, стрелки, гермоворота,
повороты и переходы формы тоннеля, которые иначе создают много уверенных
ложных срабатываний.
