# Комплект промежуточной сдачи

| Требование | Материал |
|---|---|
| Dockerfile или готовый образ | Корневой `Dockerfile` на Ubuntu 22.04 и ROS 2 Humble собирает минимальный воспроизводимый CPU-прототип |
| Работоспособный прототип | `runtime/prototype.py` реализует коридор свободного габарита и причинное подтверждение по прошлым кадрам |
| Краткое описание подхода | `docs/architecture.md` и презентация |
| Демонстрация на предоставленных данных | `demo/representative_run.mp4`, четыре реальные сцены организаторов |
| Первые результаты экспериментов | `docs/evaluation.md`, полный потоковый прогон 2 488 кадров |

Публичный reference-прототип намеренно компактен. Production-контур дополнительно
использует нормализацию плотности, локальный профиль пути, причинное подавление
фона и learned second stage. Эти компоненты проверены в Docker на CPU и Tesla
T4, а их измеренные результаты приведены в документации и демонстрации.
