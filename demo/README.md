# Демонстрация

Файл `representative_run.mp4` длится около 39 секунд и содержит четыре сцены:
человек рядом со стоящим поездом, платформа, гермоворот на повороте и стрелка.

- красная рамка — итоговая причинная тревога;
- зелёная рамка — ручной Person-трек, используемый только для оценки;
- `ЧИСТО` — геометрические предложения могут присутствовать, но итоговая
  тревога подавлена.

Видео собрано из реальных PointCloud2-кадров организаторов. Исходные bag в
публичный репозиторий не входят.
